# BTE311

Kullanılan api: https://www.themoviedb.org

Projeyi çalıştırmak için:

* `npm install`
* Ana dizinde .env dosyası oluşturun ve içine VITE_TMDB_API_KEY="kendi_api_keyiniz" ekleyin
* `npm run dev`
